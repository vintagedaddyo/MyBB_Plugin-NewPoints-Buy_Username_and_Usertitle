NewPoints - Buy Usertitle and Username

Description:

This plugin allows users change username or usertitle by paying a certain fee.

Settings:

   1) Groups allowed to change usertitle
   2) Groups allowed to change username
   3) Usertitle Change Price
   4) Username Change Price
   5) Last Changes (for the statistics page)

Statistics are shown in the ACP NewPoints Statistics page and in the NewPoints Statistics page accessible by users.
Installation

Simply upload the contents of the "Upload" folder to the root of your MyBB installation.

Then, activate Buy Usertitle and Username plugin from the Administrator Panel -> NewPoints -> Plugins.
